# Юридический ИИ-Ассистент ПСБ (Hack&Change)

Интеллектуальный юридический ассистент с RAG-поиском по нормативной документации банка, контролем актуальности редакций и защитой от галлюцинаций.

## 🚀 Быстрый запуск (за 30 секунд)

Никаких Node.js и сборок! Всё работает прямо из коробки на Python.

```bash
# 1. Установите зависимости
pip install -r requirements.txt

# 2. Запустите сервер
python main.py
