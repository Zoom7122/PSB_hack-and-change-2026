ЗАЧЕМ КАЖДАЯ СТРОКА
-------------------

.env, .env.*          ключи провайдера; в репозиторий не попадают никогда
!.env.example         шаблон без ключей разрешён — чтобы коллега знал имена переменных
artifacts/            chunks.jsonl, логи прогонов: собираются за секунды, в git не нужны
*.jsonl               любой JSONL считаем сгенерированным
!tests/fixtures/*.json  но фикстуры тестов — это данные, они в git нужны
__pycache__/, *.py[cod]  байткод Python
.venv/, venv/         виртуальные окружения
.idea/                настройки PyCharm у каждого свои
.DS_Store             мусор macOS, если кто-то откроет репозиторий на маке

ПОЧЕМУ .gitignore «не виден»
----------------------------

Файл начинается с точки — в Windows Explorer скрытые файлы по умолчанию
не отображаются. В PyCharm он виден в дереве проекта (View → Project).
Проверка в терминале:

    type .gitignore          (PowerShell)
    cat .gitignore           (Git Bash / WSL)

Если файл действительно пустой — значит при копировании через проводник
Windows создался пустой файл с тем же именем. Тогда удалить и создать заново:

    PowerShell:  New-Item -ItemType File -Name .gitignore
    затем вставить 15 строк выше и сохранить.

Проверка, что git его читает:

    git check-ignore -v .env
    → должно вывести: .gitignore:2:.env    .env
